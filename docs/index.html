为听众做的每一件事

不是通用播客 App 的套壳，每一项功能都围着这一档节目打磨。

跳过空白

自动跳过片头片尾各 2–5 分钟，起播即正片，播完自动连播下一期。

人声增强

高通滤除低频轰鸣、人声频段提亮，行车途中字字清楚；实时处理、默认关闭。

睡眠定时

倒计时或「播完本集即停」，退出界面照常生效；到点暂停，进度与通知栏保留。

倍速 0.5–3.0×

连续刻度尺 0.1 一档、齿轮震动反馈；进度条右侧直接显示剩余时间。

离线缓存

听过的内容自动缓存，重听、续播、回退 30 秒不耗流量，离线也能整集播放。

车机适配

横屏三栏、5:5 分屏、比亚迪 DiLink 日夜模式跟随，方向盘按键可控。

深色模式

跟随系统日夜切换，也可固定深色；播放面板始终保持沉浸深色。

新版本发布后在「设置 → 更新」一键升级，覆盖安装保留全部收听进度。

安装

三步开始，不用注册任何账号。

  1. 下载 APK：点页面任意「下载」按钮，或直接在 设置 → 更新 内检查新版本。
  2. 允许安装：首次安装需允许「来自此来源的应用」；签名校验通过才能升级。
  3. 覆盖安装：已装旧版本直接覆盖，收听进度、离线缓存和历史记录全部保留。
